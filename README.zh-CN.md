## 为需要时刻留意的窗口准备

点击一个窗口，按下 `fn + P`。IceScreen 会把它显示在一个小浮窗中：浮窗保持在其他窗口上方，出现在每个桌面空间，画面实时更新。单击浮窗即可跳转到来源窗口，再单击一次回到刚才使用的窗口。

IceScreen 是一个菜单栏应用，使用 SwiftUI、AppKit 和 ScreenCaptureKit 开发。全部功能免费，无账号、联网授权、使用时长限制和遥测。

## 快速开始

### 1. 安装

需要 **macOS 14 Sonoma 或更新版本**，支持 **Apple Silicon** 和 **Intel**。

1. 从[最新版本](https://github.com/inwf/IceScreen/releases/latest)下载 **[IceScreen-macOS.dmg](https://github.com/inwf/IceScreen/releases/latest/download/IceScreen-macOS.dmg)**。
2. 打开 DMG，将 IceScreen 拖到「应用程序」。
3. 从「应用程序」打开 IceScreen。

每个版本还附带应用的 ZIP 压缩包，以及用于校验下载文件的 `SHA256SUMS`。

> [!NOTE]
> 作者没有购买 Apple 开发者账号。如果 macOS 阻止打开，在「系统设置 → 隐私与安全性」中点击「仍要打开」。

### 2. 授予权限

首次启动时，IceScreen 会打开设置中的「通用 → 系统权限」。点击每一项旁边的「允许…」，在随后打开的系统设置页面中开启 IceScreen。如果 macOS 要求重新启动，请重新打开 IceScreen。

| 权限 | 用途 |
| --- | --- |
| 屏幕录制 | 在浮窗中显示窗口画面 |
| 辅助功能 | 全局快捷键、快速局部捕获和定位来源窗口 |
| 输入监控 | 全局快捷键；缺少该权限时设置页面会显示提示 |
| 通知 | 检测提醒；首次开启检测时请求 |
| 自动化 | 在 Music、TV、Spotify、Swinsian 和 VLC 中调整播放进度；首次调整进度时请求 |

### 3. 捕获第一个窗口

1. 点击需要留意的窗口，例如正在执行构建的终端。
2. 按下 **`fn + P`**，窗口出现在屏幕右下角的浮窗中。
3. 将鼠标移到浮窗上即可显示控件。保持同一个窗口在前台时再按一次 `fn + P`，即可关闭浮窗。

> [!TIP]
> 如果按下 `fn` 时还会打开表情选择器或听写，在「系统设置 → 键盘 → 按下 🌐 键时」中选择「不执行操作」，或在「设置 → 快捷键」中改用其他修饰键。

## 捕获方式

| 方式 | 默认操作 | 效果 |
| --- | --- | --- |
| 捕获窗口 | `fn + P` | 浮窗显示整个前台窗口 |
| 捕获区域 | `fn + Shift + P` | 在前台窗口上拖动选择区域。按 `Esc`、右键点击或再按一次快捷键即可取消。 |
| 快速局部捕获 | 按住 `fn` 并双击 | 捕获鼠标下方的图片、视频、表格或文本区域，并裁去对称的黑白边框 |
| 菜单栏 | IceScreen 图标 | 「捕获当前窗口」和「捕获区域」 |

快速局部捕获会结合鼠标下方的界面元素和对一张截图进行的矩形识别。在「设置 → 浮窗」中关闭「快速捕获时智能识别局部边界」后，改为放大鼠标附近的区域。按住快速捕获的修饰键时，单击会在系统双击间隔结束后送到应用，拖动则立即生效。

默认情况下，每次新的捕获会替换当前浮窗。在「设置 → 浮窗」中开启「多窗口模式」后，可以同时保留多个浮窗。同一窗口的区域浮窗按「区域 1」「区域 2」等编号，每个浮窗可以单独缩放、暂停和关闭。

来源窗口关闭或来源应用退出时，对应的浮窗会自动关闭。


## 使用浮窗

将鼠标移到浮窗上即可显示控件：

- **左上角**：关闭按钮、该应用的帧率，以及开启检测时的检测等待时间。
- **顶部**：来源应用的名称。
- **右上角**：检测状态圆点。绿色表示空闲检测，蓝色表示变化检测，画面空闲时圆点会闪烁。
- **右下角**：调整尺寸手柄。
- **左下角**：常用操作提示。
- **底部**：来源正在播放媒体时，显示播放、暂停、切换曲目按钮和进度条。

右键点击浮窗可以使用「定位来源窗口」「预览来源窗口」「暂停捕获」「恢复完整画面」、应用帧率、自动隐藏、检测方式和对比度增强。菜单栏图标中也为每个浮窗提供同样的菜单，并提供「关闭全部浮窗」。

较小的浮窗只显示部分控件，放大浮窗后即可看到帧率和等待时间按钮。

### 切换到来源窗口并返回

单击浮窗即可把来源窗口切换到前台，即使它位于其他桌面空间、已被隐藏或已最小化。再次单击同一浮窗，回到之前使用的窗口。双击浮窗会聚焦来源窗口并关闭浮窗。

单击切换可以在「设置 → 浮窗」中关闭。同一页面还可以选择来源窗口位于前台时浮窗的行为：保持浮窗、暂停捕获或关闭浮窗。

### 预览完整窗口

在浮窗上按住 `Space`，屏幕中央会以更大的尺寸显示完整的来源窗口，松开 `Space` 关闭预览。轻按一下时，预览保持打开，直到再次按下 `Space` 或点击任意位置。对于正在显示媒体的浮窗，轻按改为播放或暂停，按住超过 0.25 秒才打开预览。

### 缩放

| 操作 | 效果 |
| --- | --- |
| `⌘` + 拖动 | 放大框选的区域 |
| `⌘` + 滚动，或双指捏合 | 以鼠标位置为中心缩放 |
| 悬停后按 `=` / `-` | 放大 / 缩小 |
| 滚动 | 平移已放大的浮窗 |
| `⌘` + 双击，或悬停后按 `0` | 恢复完整窗口 |

最大可以放大 32 倍。鼠标位于浮窗上时即可双指捏合，无需先点击浮窗。

### 自动隐藏

在浮窗上双击 `fn`，即可为所有浮窗开启自动隐藏。之后鼠标移到浮窗上时，浮窗会淡出，点击直接送到下方的窗口；鼠标移开后浮窗重新显示。需要再次使用已隐藏浮窗的控件时，将鼠标移到浮窗所在位置并双击 `fn` 关闭自动隐藏。浮窗隐藏时仍然可以按 `Delete` 关闭。

「设置 → 外观 → 隐藏时透明度」决定浮窗淡出的程度。设为 100% 时，隐藏的浮窗完全透明，并在鼠标移开之前停止捕获。

### 媒体控制

来源应用向 macOS 提供播放信息时，浮窗会显示播放／暂停、上一首和下一首按钮。时长已知的媒体还会显示可拖动的进度条。悬停时按 `←` / `→` 后退或前进 5 秒。

直播、无法跳转的媒体，以及不提供播放信息的应用，只显示部分控件或不显示控件。Music、TV、Spotify、Swinsian 和 VLC 通过应用自动化调整进度，因此首次调整时 macOS 会请求权限。媒体选项位于「设置 → 媒体」。

### 台前调度

来源窗口位于台前调度的其他分组时，浮窗会暂停并显示「返回来源窗口」。点击即可切换到该分组，捕获自动继续。


## 快捷键与手势

以下操作在鼠标位于浮窗上时生效，无需先点击浮窗。

| 操作 | 效果 |
| --- | --- |
| 拖动 | 移动浮窗 |
| 拖动边缘或右下角手柄 | 保持内容比例调整尺寸 |
| 单击 / 双击 | 在来源窗口与之前的窗口之间切换 / 聚焦来源窗口并关闭浮窗 |
| `Space` | 预览来源窗口，或播放和暂停媒体 |
| `←` / `→` | 媒体后退 / 前进 5 秒 |
| `=` / `-` / `0` | 放大 / 缩小 / 恢复完整窗口 |
| `F` | 选择该应用的帧率 |
| `D` / `C` / `S` | 切换空闲检测 / 变化检测 / 细微变化检测 |
| 双击 `fn` | 切换所有浮窗的自动隐藏 |
| `Delete` | 关闭浮窗 |

在「设置 → 快捷键」中可以修改捕获快捷键、快速捕获的修饰键，以及用于双击的修饰键（`fn`、`⇧`、`⌃`、`⌥` 或 `⌘`）。区域快捷键默认在窗口快捷键的基础上增加一个修饰键，例如 `⌘⇧I` 对应 `⌥⇧⌘I`，也可以单独设置。还可以开启关闭全部浮窗的快捷键，默认为 `⌘⇧P`。设置冲突的快捷键时会显示提示。

## 内容检测

IceScreen 可以持续观察浮窗，在画面出现变化时提醒你。在「设置 → 检测与自动化」中为所有新浮窗开启检测方式，或者通过 `D`、`C`、`S`、右键菜单或状态圆点为单个浮窗设置。

| 检测方式 | 提醒时机 | 等待时间 |
| --- | --- | --- |
| 空闲 | 画面停止变化，例如构建或下载结束 | 5–120 秒，默认 20 秒 |
| 变化 | 画面静止后再次出现变化，例如新的日志行或聊天消息 | 1–120 秒，默认 10 秒 |
| 细微变化 | 为以上两种方式使用更精细的采样，适合加载指示器和细进度条 | — |

点击浮窗顶部的等待时间，可以只为该浮窗设置等待时间。浮窗暂停、完全隐藏或 Mac 睡眠时检测会暂停，恢复后重新计时。点击通知即可把来源窗口切换到前台。

### 运行命令

在「检测与自动化 → 运行 Shell 命令」中填写命令后，每当浮窗检测到空闲或变化，IceScreen 会通过 `/bin/sh` 运行该命令。命令可以读取以下环境变量：

| 变量 | 内容 |
| --- | --- |
| `ICESCREEN_EVENT` | `idle` 或 `change` |
| `ICESCREEN_APP` | 来源应用名称 |
| `ICESCREEN_BUNDLE_ID` | 来源应用的 bundle ID |
| `ICESCREEN_WINDOW_ID` | 来源窗口 ID |
| `ICESCREEN_WINDOW_TITLE` | 来源窗口标题 |

例如，构建结束、画面静止时让 Mac 朗读提示：

```bash
[ "$ICESCREEN_EVENT" = idle ] && say "$ICESCREEN_APP has finished"
```

每个浮窗同时只运行一个命令，命令运行期间的新事件会被跳过。命令超过执行超时（5–300 秒，默认 15 秒）、浮窗关闭或 IceScreen 退出时，命令会被终止。命令输出不保存，非零退出状态会显示为错误。清空该输入框即可关闭命令。


## 外观与性能

「设置 → 外观」顶部提供即时预览。可以使用内置示例，或点击「选择图片…」用自己的图片查看效果；「对比原图」显示未增强的画面。

| 设置 | 默认值 |
| --- | --- |
| 圆角，0–30 pt | 14 pt |
| 普通透明度 | 0%（不透明） |
| 增强对比度和锐度，两项强度分别调整 | 关闭，均为 50% |
| 自动隐藏的隐藏时透明度 | 100%（完全透明） |
| 悬停时控件周围变暗，以及边缘效果强度 | 开启，100% |
| 显示操作提示 | 开启 |

点击滑块下方的圆点即可恢复默认值。

帧率按应用分别设置，可选 1、5、10、15、24、30、60 FPS，默认 10 FPS。帧率越低越省电；终端和日志使用 1–5 FPS 即可，视频使用 30–60 FPS 效果最好。在浮窗上按 `F` 即可为该应用修改帧率。「设置 → 浮窗」可以设置默认帧率，并重置各应用的帧率。捕获分辨率跟随浮窗在屏幕上的尺寸，最长边上限为 4096 像素。浮窗暂停、完全隐藏或 Mac 睡眠时停止捕获。

「设置 → 浮窗」还可以设置新浮窗出现在屏幕上的位置，以及是否显示在全屏应用上方。「设置 → 通用」可以开启登录时启动，也可以隐藏菜单栏图标；隐藏后从「应用程序」再次打开 IceScreen 即可回到设置。

界面语言在「设置 → 通用 → 界面语言」中切换，支持简体中文和 English，切换后立即生效。


## 命令行

应用的可执行文件接受参数，可以在脚本和启动器中使用：

```bash
ICESCREEN=/Applications/IceScreen.app/Contents/MacOS/IceScreen
"$ICESCREEN" --app Terminal
"$ICESCREEN" --app Terminal --window build --zoom bottom-left:4x
"$ICESCREEN" --window 12345 --region
```

| 参数 | 说明 |
| --- | --- |
| `--app NAME` | 应用名称的一部分，或完整的 bundle ID；不区分大小写 |
| `--window TITLE_OR_ID` | 窗口标题的一部分，或数字窗口 ID |
| `--zoom POSITION:FACTOR` | 初始放大到 `top-left`、`top`、`top-right`、`left`、`center`、`right`、`bottom-left`、`bottom` 或 `bottom-right`，倍率 1–32 |
| `--region` | 在匹配的窗口上选择区域 |
| `--help` | 显示用法 |

不指定 `--app` 或 `--window` 时，IceScreen 捕获前台窗口。标题匹配到多个窗口时，需要同时指定 `--app` 或改用窗口 ID。IceScreen 已在运行时，请求会交给正在运行的应用，命令在请求送达后立即退出；3 秒内没有收到回应则返回错误。找不到窗口等问题会显示在设置窗口中。不带参数运行时，在正在运行的应用中打开设置。


## 常见问题

**按 `fn + P` 没有反应。** 在「设置 → 通用」中确认已允许辅助功能。如果设置页面提示全局按键尚未启用，还需要在「系统设置 → 隐私与安全性 → 输入监控」中允许 IceScreen，再点击「重新检查权限」。

**浮窗是黑色的或画面不更新。** 允许屏幕录制并重新启动 IceScreen。部分受保护的内容（例如 DRM 视频）无法捕获，最小化的窗口在恢复显示之前不会更新。

**更新后权限反复失效。** macOS 按应用所在位置记录权限。请将 IceScreen 保留在「应用程序」中，替换前先完全退出，再打开新版本。

**系统录屏提示中显示旧图标。** macOS 在当前登录会话中缓存该图标，退出登录后重新登录即可刷新。

**没有显示媒体控制。** 来源应用需要向 macOS 提供播放信息。请确认「设置 → 媒体」中已开启「显示来源媒体的播放控制」。


## 从源码构建

需要 macOS、Xcode 26 或更新版本、[uv](https://docs.astral.sh/uv/)，以及用于生成 DMG 背景的 Cairo（`brew install cairo`）。

```bash
git clone https://github.com/inwf/IceScreen.git
cd IceScreen
bash scripts/build.sh
open dist/IceScreen.app
```

该命令为当前 Mac 生成 `dist/IceScreen.app` 和 `dist/IceScreen-macOS.dmg`。设置 `UNIVERSAL=1` 可以同时为 Apple Silicon 和 Intel 构建。测试和开发检查见[参与开发](CONTRIBUTING.zh-CN.md)，各版本的变化见 [CHANGELOG.md](CHANGELOG.md)。
